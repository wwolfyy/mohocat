## 0. Where we are (read first)

**§7a "bake the data layer" is DONE** (the 🔴 prominent perf item). Cats are now read
**server-side via the Admin SDK** and baked into the home + adoption **Server Components**
with **ISR**; the client-side Firestore cat-query waterfall is **gone** on both baked
surfaces. Freshness is the **hybrid** model agreed with the user: **on-demand
revalidation** on admin cat-edits (instant) + a **1h ISR backstop** (`revalidate = 3600`).

**Verified:** browser (dev) — landing pins show avatars on first paint, marker-click gallery
opens with **zero** new Firestore requests; adoption card server-rendered. `next build` —
both routes ISR with `initialRevalidateSeconds: 3600`. `tsc` clean, smoke **25/25**.

**One follow-up carried:** mechanical removal of the now-dead **static-data export seam**
(decided, not yet done — see §3 below).
