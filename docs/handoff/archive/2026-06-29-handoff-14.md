## 1. The grid (core editor)

- **Files:** `src/components/admin/cat-grid/CatGrid.tsx` (view) +
  `src/components/admin/cat-grid/selectColumn.tsx` (a custom native-`<select>` column — the lib ships
  no select; one component drives both string enums and the boolean `isNeutered`).
- **Tab host:** `src/app/admin/cats/page.tsx` gained a `view: 'card' | 'grid'` tab switch; the card
  UI is unchanged, just wrapped.
- **Typed columns** for the full field set; `date_of_birth` uses a grouping-free `createTextColumn`
  (plain `intColumn` rendered years as "2,016").
- **Save model:** edits accumulate in local state; **전체 저장** commits every dirty cell as **one
  Firestore `writeBatch` of per-field `update()`s** via the new
  `catService.batchUpdateCats()` (interface + impl in `src/services/interfaces.ts` /
  `src/services/cat-service.ts`, mirroring `batchUpdateImages`). Partial, non-destructive — app-only
  fields like `adoptable` are never wiped. After commit → `triggerCatRevalidate(user)` → reload.
- **Validation:** `isNeutered` / `date_of_birth` are **mandatory** — a _dirty edit may not clear
  them_ (would write `undefined`/blank); untouched empties are fine (never in a patch).
  `ignoreUndefinedProperties` stays off. UX = inline **red cell highlight** + **summary banner** +
  **block-save-until-clean** (handoff-13 said "prototype a couple" — both shipped; pick one later if
  desired).
- **Edit-only:** `lockRows` (no add/delete in the grid; creation/deletion stay in the card view).

## 2. Filter / sort / select / bulk-edit (this session)

Confirmed decisions: **full filter parity** with the card view; **bulk-edit on the 8 categorical +
year fields**.

- **Shared filter/sort util — `src/utils/cat-filters.ts` (new).** Extracted the card view's
  previously-inline logic into pure functions: `filterCats`, `sortCats` (type-aware, any `keyof Cat`),
  `getUnique{Locations,Statuses,Genders,BirthYears}`, `CatFilterState`/`EMPTY_CAT_FILTERS`. **Both**
  the card view (`page.tsx`, rewired — behaviour preserved) and the grid now use it (single source of
  truth).
- **Filter:** search box + collapsible 필터 panel (status / location / gender / birth-year /
  neutering / adoptable) + 필터 초기화, with a live "N / total마리" count.
- **Sort:** clickable column headers toggle asc↔desc (caret indicator).
- **Select:** checkbox **gutter** column + **select-all** header checkbox; selection persists across
  filtering.
- **Bulk-edit:** toolbar (shown when ≥1 row selected) — field picker (status, dwelling,
  prev_dwelling, isNeutered, adoptable, sex, dob_certainty, date_of_birth) + a typed value editor +
  적용 / 선택 해제. Applies the value to selected rows via the same dirty-state model (so it flows
  through the normal validated Save).
- **View plumbing (key invariant):** the full `rows` array (keyed by `id`) is the source of truth.
  `displayedRows = filterCats → sortCats → map(bake __selected)`; the grid's `onChange` merges edits
  back into `rows` **by id** (stripping the transient `__selected`). So filter/sort/selection never
  touch the save path, and a **dirty row hidden by a filter still saves** (dirty count is across all
  rows).
