## 7. Gotchas / notes

- **Native checkbox color:** the permission-matrix checkboxes use `text-brand-500` (was
  `text-blue-600`), but there's **no `@tailwindcss/forms`**, so `text-*` is inert on native
  checkboxes — they still render the browser-default (blue) check. Left intentionally (yellow
  fill on white is low-contrast; native legibility wins). Use `accent-brand-500` if you ever
  want them branded.
- **Pre-existing console errors:** `/admin` logs two `Failed to load permission config from
Firestore: Missing or insufficient permissions` errors — **pre-existing**, unrelated to this
  work (permission-config load). Not introduced here.
- **app-management green save-flash:** the success-state override needed `bg-none bg-green-600
text-white` to cleanly beat the new gradient `primary` (twMerge keeps gradient stops
  otherwise).
