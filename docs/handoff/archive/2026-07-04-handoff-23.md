## 7. Gotchas / notes

- **Mobile is unverifiable with current tooling** — see §6. Do not repeat the "code-verified
  only" pattern for the actual mobile pass; fix the tooling first.
- **`resize_window` "succeeds" but lies** — it returns success and changes the OS window, but
  the rendered viewport / screenshot stays desktop-width. Don't trust it for responsive checks.
- **Preflight `img{max-width:100%}` clamps fixed-size images in tight flex/table cells** — if a
  thumbnail looks squished, suspect the container width before the image itself (`max-w-none`
  fixes it). See DEBUG_LOG 2026-07-03.
- **Albums-public is a CMS toggle, not code** (§4a) — the code default still gates them by
  design.
- **Map cluster radius is now `mountains.json` config** (§3), screen-pixel + mobile-only; a
  change still needs a push + rebuild (no runtime dial).
