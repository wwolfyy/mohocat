## 1. Mobile lightbox — pinch-to-zoom (`2dde944`)

Added `react-zoom-pan-pinch` (v4.0.3, new dependency) to `Lightbox.tsx`. On mobile only
(`useIsMobile`, <768px) the image is wrapped in `TransformWrapper`/`TransformComponent`:
pinch 1–4×, drag-to-pan while zoomed, double-tap toggles zoom, prev/next navigation resets
to fit (`key={image.imageUrl}` remount). Desktop rendering unchanged (no wrapper mounted).

Touch-action flips between `pan-y` (un-zoomed, single-finger scrolls the overlay) and `none`
(zoomed, drags pan the photo). App-wide `viewport.maximumScale: 1` is intentionally left in
place — page-level zoom would fight the Leaflet map and scale the fixed lightbox chrome.

**Gotcha:** The rAF animation loop can't tick in a backgrounded automation tab (verified 0
ticks/s) — zoom animation must be tested on a real device.

## 2. Back button / swipe-back closes modals (`46acef1`)

`useModalLayer` now pushes a synthetic `history.pushState({ mohocat_modal: id }, '')` entry
when each overlay opens. A module-level `popstate` listener (registered once, lazily) closes
the topmost layer on back-gesture instead of navigating away from the page. Normal close (X,
backdrop, Escape) pops the entry via `history.back()` with a `suppressNextPopState` flag so
it doesn't cascade to the layer below.

All three overlay types (Modal, Lightbox, VideoPlayer) are covered via the shared hook. The
nested case (e.g. album opened from cat modal) handles correctly — each has its own entry and
each back press peels one layer.
