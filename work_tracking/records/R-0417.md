**Owner's call, 2026-08-09.** Shrinking `HANDOFF.md` was Phase 4 work. It was pulled forward into
the Phase 2 import and done in the same commit that added its 57 rows.

**Why it could not wait:** the hand-off's decisions were **scattered through its narrative**
rather than gathered in a section. Cutting only the open-items list — the mechanical part — would
have left all 36 imported decisions still sitting in prose, in a file the migration had just
declared no longer authoritative. That is precisely the half-migrated state the plan forbids, and
it would have persisted until Phase 4.

**Result:** `HANDOFF.md` went **3,396 → ~150 lines**. The body is frozen at
`docs/handoff/archive/2026-08-09-handoff-living-doc.md`, its relative links repointed one level
for the move and all 53 verified to resolve; `git show 2e07e3e:docs/handoff/HANDOFF.md` is the
byte-exact original, and every record's `source_ref` pins that same commit.

📌 The rule this is an instance of — **move an item and delete its origin in the same change** —
is a watch-out carried from the design, and it is the one the whole per-file gate in `R-0409`
exists to serve.
