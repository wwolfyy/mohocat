# R-0446 — README.md labels the hand-off with a path it no longer has, and link-check cannot see it

> **task · open** · 2026-08-10
> Found on 2026-08-09 while auditing what the repo says about the hand-off. Recorded as its own
> item on 2026-08-10 under R4.

---

**`README.md:13` reads:**

```markdown
- **[`docs/handoff/HANDOFF.md`](./work_tracking/HANDOFF.md)** — current engineering state and
  what's next. Read it first when picking work up.
```

**The target is right and the label is a year out of date.** `R-0428` moved the file to
`work_tracking/` and repointed the link; the visible text still names the old path. A reader
following the repo's front door is told to look somewhere that has not existed since the
restructure.

⚠️ **`link-check.js` is silent here and always will be — it checks targets, not link text.** There
is no general fix for that: link text is prose, and prose that happens to look like a path is
indistinguishable from prose that is one. 🔑 **A stale label is a different defect from a dead
link**, and only the second is mechanically detectable.

📌 **Worth a scan rather than a one-line fix.** The same shape — text naming a pre-`R-0428` path
while the link resolves correctly — can exist anywhere the migration repointed a link, and
`R-0428` repointed many. Fixing only the instance that happened to be noticed leaves the class.
